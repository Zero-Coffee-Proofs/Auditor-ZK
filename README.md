# Auditor ZK

**Auditor ZK** is a platform for creating and trading **RWA-backed tokens** over the Midnight Blockchain using [**TLSNotary**](https://tlsnotary.org/). It allows issuers to tokenize real-world assets while preserving privacy and ensuring trustless, verifiable reserve proofs.

The current implementation integrates [TLS Notary](https://github.com/tlsnotary/tlsn/) for our [Plaid](https://plaid.com/docs/link/) usage, we managed to have an actual real-world use case for this service without the system having access to any information nor relying on self-attestation.
