# Auditor ZK

**Auditor ZK** is a platform for creating and trading **RWA-backed tokens** over the Midnight Blockchain using **TLSNotary**. It allows issuers to tokenize real-world assets while preserving privacy and ensures trustless, verifiable reserve proofs.
